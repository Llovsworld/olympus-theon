# Política de conservación y supresión

Versión: 2026-08-30.

| Información | Periodo operativo | Acción al finalizar |
| --- | --- | --- |
| Consulta por formulario o correo | Hasta 12 meses desde la última comunicación | Eliminar del buzón y papelera, salvo obligación, contrato o reclamación. |
| Conversación por WhatsApp | Hasta 12 meses desde la última comunicación si no nace una relación contractual | Eliminar la conversación y archivos descargados, salvo obligación, contrato o reclamación. |
| Suscripción pendiente | Token válido 24 horas; registros pendientes se depuran si llevan más de 30 días caducados | Borrado del registro pendiente. |
| Suscripción activa | Hasta la baja | Desactivar de inmediato y cesar envíos. |
| Baja y prueba de consentimiento | Mínimo necesario para acreditar la baja, impedir nuevos envíos y atender responsabilidades | Revisar anualmente; suprimir o anonimizar cuando ya no sea necesario. |
| Logs técnicos | Mínimo disponible y necesario según configuración del proveedor | Configurar la retención más corta compatible con seguridad; no copiar mensajes personales a logs. |
| Métricas agregadas | Mientras sean útiles para evolución histórica | Conservar solo datos agregados; eliminar exportaciones identificables si aparecieran. |
| Imágenes y archivos públicos | Mientras el contenido esté publicado o exista autorización | Retirar de la página y del almacenamiento; revisar archivos huérfanos trimestralmente. |
| Borradores del panel | Hasta publicación, descarte o limpieza del navegador administrador | Eliminar manualmente tras publicar o abandonar el borrador. |

## Reglas de ejecución

- Revisión el primer día hábil de enero, abril, julio y octubre.
- Registrar fecha, categoría revisada, número de elementos eliminados y persona que ejecuta la revisión; no anotar el contenido eliminado.
- Si existe litigio, obligación fiscal o solicitud de autoridad, bloquear solo la información necesaria y documentar el motivo.
- Las copias de seguridad deben caducar conforme a la política del proveedor y no utilizarse para restaurar datos previamente suprimidos salvo desastre técnico justificado.
